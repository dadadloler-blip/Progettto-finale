# presentazione
Il mio progetto è un gioco di traduzione in Python che utilizza le librerie sounddevice e speech_recognition per l'analisi vocale.
Ho sviluppato il software integrando i moduli googletrans e scipy per gestire la traduzione e il salvataggio dei file audio wav.
Il sistema offre quattro livelli di sfida, da facile a estremo, con una selezione di parole molto più varia rispetto al passato.
Rispetto alla versione precedente, ho aggiunto funzioni avanzate e termini complessi per testare la precisione della pronuncia.
Questa applicazione trasforma lo studio delle lingue in un'esperienza interattiva basata sul confronto immediato tra voce e testo.
